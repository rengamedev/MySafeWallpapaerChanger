# Wallpaper Rotator

Минимальная утилита для Windows 10/11, которая автоматически скачивает обои с Wallhaven или NASA Image Library и устанавливает их через WinAPI. У приложения нет телеметрии, рекламы, автообновления, фоновой службы и сторонних NuGet-зависимостей.

## Возможности

- Wallhaven (70% по умолчанию): `general + anime`, SFW, минимум — разрешение основного экрана при первом запуске, включая топ за последний месяц.
- NASA Images (30%): случайный запрос из настраиваемого списка, оригинальный/крупный JPEG. Размер снимка проверяется по заголовку файла до полной загрузки.
- Два расписания: один раз в новый календарный день (при запуске, пробуждении, разблокировке и раз в 15 минут, если компьютер не засыпает) либо через заданный интервал, отсчитываемый от последней успешной смены — перезапуск приложения его не сбрасывает.
- Ручной выбор темы и конкретного изображения из сетки до 10 случайных превью Wallhaven. Ручной выбор не меняет настройки автоматической ротации.
- Меню в трее: история назад на несколько шагов, отмена долгой загрузки, избранное, «Больше не показывать эти обои», пауза автоматической смены и опциональный автозапуск.
- Расположение обоев: заполнение, по размеру, растянуть, по центру, замостить, расширение на все мониторы или «не менять».
- Проверка HTTPS-домена, HTTP/MIME, размера файла, декодируемости, разрешения и ориентации; зависшая загрузка прерывается.
- История последних 10 файлов и ссылка на источник каждого текущего изображения.
- Опциональный Wallhaven API-ключ хранится через Windows DPAPI и никогда не записывается в конфигурацию или лог; ключ можно проверить прямо в диалоге.

## Сборка и проверка

Требуется официальный .NET 8 SDK для Windows x64 (версия закреплена в `global.json`). Самый простой способ — запустить `build.cmd`: он выполнит тесты и соберёт EXE.

```powershell
dotnet restore WallpaperRotator.sln
dotnet build WallpaperRotator.sln -c Release --no-restore
dotnet test WallpaperRotator.sln -c Release --no-build
dotnet publish src/WallpaperRotator/WallpaperRotator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:ContinuousIntegrationBuild=true -o outputs/WallpaperRotator-win-x64
```

Сборка использует встроенные анализаторы .NET, а предупреждения считаются ошибками. Форматирование проверяется командой `dotnet format whitespace --folder --verify-no-changes`.

Список зависимостей можно проверить командой:

```powershell
dotnet list src/WallpaperRotator/WallpaperRotator.csproj package --include-transitive
```

Ожидаемый результат — отсутствие package references. Пакеты xUnit используются только тестовым проектом и в EXE не попадают. SHA-256 опубликованного файла:

```powershell
Get-FileHash outputs/WallpaperRotator-win-x64/WallpaperRotator.exe -Algorithm SHA256
```

### Непрерывная интеграция и релизы

`.github/workflows/tests.yml` на каждом pull request собирает решение на Ubuntu, проверяет форматирование и отсутствие NuGet-зависимостей; тесты на Windows идут раз в сутки и по кнопке Run workflow. Зелёный PR сливается сам (`auto-merge.yml`). `.github/workflows/build.yml` по тегу вида `v1.2.3` (или по кнопке) собирает решение на `windows-latest`, запускает тесты, публикует EXE как артефакт вместе с `SHA256SUMS.txt` и `build-info.txt` (коммит и версия SDK) и создаёт GitHub Release с этими файлами.

Чтобы сверить хэш со своей сборкой, используйте ту же версию SDK, что указана в `build-info.txt`, и флаг `-p:ContinuousIntegrationBuild=true` (его уже передаёт `build.cmd`).

## Использование

Запустите `WallpaperRotator.exe`. Пункт «Выбрать и сменить обои…» или двойной щелчок по значку в трее открывает выбор темы, собственного запроса и режима контента, а затем сетку до 10 превью. Оригинал скачивается только после выбора карточки. Выбор темы запоминается отдельно от автоматической ротации, а пункт «Следующие обои» выполняет автоматическую ротацию без открытия диалога. Пока идёт загрузка, её можно прервать пунктом «Отменить загрузку».

«Предыдущие обои» с каждым нажатием переходит на шаг назад по истории. «Добавить в избранное» копирует текущий файл в `%LocalAppData%\WallpaperRotator\favorites`, где он не удаляется при очистке истории. «Больше не показывать эти обои» исключает изображение из будущих подборок и сразу загружает другое; список скрытых можно очистить в настройках.

В «Настройках…» выберите расписание, расположение обоев и режим автоматической ротации:

- `Случайный` — прежняя случайная смесь Wallhaven и NASA по заданным весам;
- `Топ Wallhaven` — случайное не использованное недавно изображение из топа за месяц (первые пять страниц);
- `Смешанный` — топ Wallhaven и случайные NASA по заданным весам.

Кнопка «Как у экрана» подставляет разрешение основного монитора в минимальные размеры. Уведомления об успешной смене можно отключить; предупреждения об ошибках остаются.

Для ежедневной смены включите в меню трея «Запускать вместе с Windows». Успешная смена выполняется не чаще одного раза за локальную календарную дату; после неудачи приложение повторит попытку в течение 15 минут, а также при пробуждении или разблокировке. В режиме «Каждые N часов» неудачная попытка повторяется через 15 минут. «Пауза автоматической смены» останавливает только расписание — ручные действия продолжают работать.

Конфигурация сохраняется в `%LocalAppData%\WallpaperRotator\config.json`, а время последних успешных смен и список скрытых обоев — в `state.json`; полный пример конфигурации находится в `config.example.json`. Если `config.json` повреждён, приложение загрузит безопасные значения и сохранит исходный файл как `config.json.invalid`.

Для sketchy/NSFW откройте «Ключ и контент Wallhaven…», введите личный ключ, при желании нажмите «Проверить ключ» и явно отметьте нужные категории. Без сохранённого ключа приложение всегда запрашивает только SFW. Ключ передаётся Wallhaven в заголовке `X-API-Key`, а не в URL.

Приложение соединяется только с:

- `wallhaven.cc` — официальный API;
- `w.wallhaven.cc` — файлы Wallhaven;
- `th.wallhaven.cc` — миниатюры для ручного выбора;
- `images-api.nasa.gov` — официальный API NASA;
- `images-assets.nasa.gov` — файлы NASA (ссылки из API переводятся на HTTPS).

Сведения об авторе/центре и ссылка на источник сохраняются в `history.json`. Материалы могут иметь отдельные ограничения правообладателей; приложение рассчитано на личное использование.

## Данные и удаление

Все пользовательские данные находятся в `%LocalAppData%\WallpaperRotator`. Чтобы полностью удалить программу:

1. Снимите флажок «Запускать вместе с Windows» и завершите приложение.
2. Удалите EXE и каталог `%LocalAppData%\WallpaperRotator`.

Приложение не создаёт задач Планировщика, служб, драйверов или системных файлов.

## Диагностика и модель безопасности

Ошибки без URL и секретов записываются в `%LocalAppData%\WallpaperRotator\diagnostics.log`, включая непредвиденные исключения — приложение не закрывается из-за них. Загрузчик принимает изображения только с двух разрешённых CDN-доменов, ограничивает объём потока, прерывает загрузку, если данные не поступают дольше минуты, и проверяет изображение до изменения рабочего стола. При исчерпании попыток текущий фон не меняется. При ответе Wallhaven 429 (лимит запросов) следующая попытка выполняется с паузой.

При запуске удаляются файлы обоев, на которые не ссылается история, и временные файлы прерванных загрузок старше часа.

Перед распространением EXE рекомендуется проверить его Microsoft Defender и сверить SHA-256 со сборкой из исходников.
